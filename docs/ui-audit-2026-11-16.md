# Аудит интерфейса и юзабилити — 16.11.2026

(2 января), открытая карточка узла, Гант, мобильный чат, экран «Модель». Три ширины:

## Метод

- Playwright (chromium) снимает скриншоты и измеряет DOM: переполнение страницы, скроллы
  контейнеров, размеры интерактивных элементов, размеры шрифтов, контраст (WCAG-формула),
  позицию карточки после клика, доступность с клавиатуры (Tab/Enter/Escape).
- **axe-core 4.14.1**, теги WCAG 2.1 A/AA — машинные нарушения.
- Ручные сценарии: перемотка дня шкалой и сценарием, слайдер стрелками, фильтр по заявке,
  открытие карточки, фокус после клика, Tab-порядок на «Модели» и в Ганте.

Артефакты: `docs/screenshots/audit/audit.json` + 8 скриншотов; воспроизвести:
`bun run serve:demo` в одном терминале и `bun run audit` в другом.

## P0 — блокирует основные сценарии

### 1. Список 30 заявок в «Модели» работает только мышью

`renderList` рисует `<li class="row" data-action="select">` без `tabindex`, `role` и
обработчика клавиатуры. Замер: 12 нажатий Tab проходят по меню (3 ссылки) и 9 кнопкам
(`+4 ч`, массовый шаг, сброс, 7 ролей) — **ни одна строка списка не получает фокус**.
Выбрать заявку, а значит и открыть карточку, с клавиатуры нельзя.

**Починить:** либо сделать строку `<button>` внутри `<li>`, либо дать `role="button"`,
`tabindex="0"` и Enter/Space в делегированном `keydown` (по аналогии с кликом).
**Тест:** e2e — Tab до первой строки, Enter → `.row.active` и заголовок карточки.

### 2. Точки Git-графа не активируются с клавиатуры

У коммитов есть `tabindex="0"`, они получают фокус, тултип по фокусу показывается, но
**Enter/Space не открывают карточку** (`focus` → Enter → карточки нет на всех трёх ширинах):
обработчик только `click`. Плюс у `<g>` нет `role`/`aria-label`, а `<svg role="img">`
без имени — axe `svg-img-alt` (serious, 3/3 вьюпорта): для скринридера это «картинка» без
подписи, а вложенные фокусируемые точки противоречат роли image.

**Починить:** `role="button"`, `aria-label` вида «З-015, U6, 2 января, депутат-диспетчер,
SLA в срок»; Enter/Space в `wireBody`; имя для SVG (`aria-label` или `<title>`), либо
убрать `role="img"` и дать `role="group"` + описание.

## P1 — серьёзно мешает

### 3. Фокус теряется, карточка не закрывается Esc

После клика по коммиту `paintBody` заменяет DOM, и `document.activeElement` = **BODY**;
фокус не переходит в карточку. `Escape` карточку не закрывает (проверено: счётчик
`[data-node-card]` остаётся 1). Позиция карточки при этом нормальная: top = 905 / 723 / 764 px
при высоте окна 950 / 768 / 844 — видна без прокрутки.

**Починить:** `tabindex="-1"` карточке и `card.focus()` после рендера; Esc → закрыть и
вернуть фокус на коммит; закрывать по клику вне карточки.

### 4. Перемотка дня не обновляет адрес

Клик по дню шкалы «5 января» меняет подпись и данные (`5 января 2026 · заявок 30`), но
`location.hash` остаётся `#timeline?at=2026-01-02`. Сценарийная кнопка — так же. URL
обновляет только слайдер по событию `change` (стрелка → `at=2026-01-06`). Итог: ссылка
«поделиться» и перезагрузка показывают другую дату.

**Починить:** `history.replaceState` с `hrefTimeline(day, view)` внутри `jumpTo` (и при
смене вида), а не только в обработчике слайдера.

### 5. Сброс фильтра не появляется

В шапке есть условная кнопка «Показать все заявки» (`data-action="clear"`), но шапка не
перерисовывается в `paintBody` — после выбора чипа кнопки нет (`clearAfterFilter = 0`).
Сбросить фильтр можно только повторным кликом по тому же чипу, и это нигде не написано.

**Починить:** перерисовывать блок `.controls` в `paintBody` или всегда рендерить кнопку
сброса с `hidden`/disabled; подписать «Сбросить фильтр (З-015)».

### 6. Горизонтальные скроллы без ориентиров

| Контейнер | 1440 | 1024 | 390 |
|---|---|---|---|
| `.canvas` (граф/Гант) | 1082 / **1438** | 990 / **1438** | 356 / **1438** |
| `.chips` (28 заявок) | 1440 / **1503** | 1024 / **1503** | 390 / **1503** |

На мобильном граф в 4 раза шире экрана, полоса чипов — в 3,8 раза. Нет ни fade-маски, ни
стрелок, ни подсказки «прокрутите», заголовки узлов не закреплены — при вертикальном скролле
колонки U1…U30 уезжают. На Ганте `.canvas` ещё и не фокусируется (axe
`scrollable-region-focusable`, serious): с клавиатуры его не прокрутить. Строки Ганта
(`div[data-row]`) и полосы (`div[data-bar]`) — тоже только мышь.

**Починить:** `tabindex="0"` + `aria-label="Прокручиваемая диаграмма"` для `.canvas`;
строки Ганта — `role="button"`/`tabindex` + Enter; для чипов — перенос строк на ширине
< 900px или select; sticky-заголовки колонок; визуальная подсказка прокрутки.

### 7. Контраст 4,44:1 на подписях автора и времени в «своих» пузырях

axe `color-contrast` (serious, 2 узла на каждом из 5 экранов): `.own > .bubble > .author`
и `.time` — 10 px, `--dim #98a2b3` на фоне `#1f3b5c`. Замер: **4.44:1** при пороге 4.5:1.
Остальной тёмный интерфейс проходит.

**Починить:** для своего пузыря поднять цвет до `#c7d2e2` (≈5.6:1) или фон до `#17293f`;
заодно 10 → 11 px.
