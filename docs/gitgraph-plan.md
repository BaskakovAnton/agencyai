# План: Git-граф с перемоткой времени + мобильный чат

> Задача от 16.11.2026 (спека владельца). Порядок работы — по правилу проекта: план → тесты → реализация → зелёные → деплой.

## Что меняется

| Было | Станет |
|---|---|
| `#dashboard` — таблица когорт (Chart.js stacked bars) | `#timeline` — **Git-граф** заявок (SVG) с ползунком времени и переключателем «Гант» |
| `#chat` — сценарный плеер одной заявки З-015 | `#chat/<заявка>?at=<день>` — **мобильный мессенджер** для любой из 30 заявок, синхронный по дате |
| Когорты срочности как основа интерфейса | Убраны: развилки процесса заменяют их (приоритет остаётся только меткой SLA) |

Терминальная модель (`src/cli`, `bun test`) не меняется — новые модули добавляются рядом.

## Данные: даты в модели

- `Move.at?` — когда произошёл переход (ISO);
- `Incident.createdAt?` — когда заявка создана;
- `src/core/timeline.ts` (чистые функции): `withTimeline`, `incidentAt`, `visibleAt`, `historyUpTo`, `daysRange`, `formatDay`;
- `src/core/story.ts` — демо-история: 30 заявок стартуют с U1 (общий корень), создаются каждые 12 ч начиная с 20 декабря, затем 5 массовых шагов вперёд → ветки расходятся по развилкам (U9 → U10/U16/U6, U12 → U13/U19, U13 → U10/U6/U14). Диапазон ползунка: 20 декабря — начало января.

## Экраны

### 1. `#timeline` — Git-граф

- SVG: колонки = узлы U1…U30, строки = дни, точки = «коммиты» (заявка на узле в конкретный день), линии = путь заявки;
- клик по точке → `#chat/<заявка>?at=<день>`;
- **ползунок времени** `input[type=range]`: перерисовывает граф, скрывая события позже выбранного дня;
- переключатель **«Гит-граф» / «Гант»** — fallback с теми же данными;
- полоса заявок для фильтра по одной заявке; подпись даты «2 января 2026»;
- тултип при наведении: заявка, узел, дата, роль, SLA.

### 2. `#chat/<заявка>?at=<день>` — мобильный чат

- макет телефона (скруглённые углы, тень, адаптивная ширина), пузыри сообщений, аватары ролей, время у каждого сообщения;
- **никаких полей ввода и кнопок «Отправить»** — это плеер переписки;
- сообщения строятся из истории заявки: узел → роль → реплика (`src/data/messages.ts`, тексты U1/U6/U7/U19 — дословно из спеки);
- при смене узла автоматически меняются «Вы общаетесь как» и собеседник;
- «Сменить роль (симуляция)» — взгляд с другой стороны на ту же дату;
- «Следующий узел» перематывает дату к следующему событию заявки и обновляет `at` в адресе (состояние общее с графом).
