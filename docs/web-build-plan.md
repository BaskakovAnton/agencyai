# План: прод-сборка модели для GitHub Pages

## Решения (16.11.2026)

- Узлы: **30 из `deput`** (6 групп, 7 ролей) — источник уже перенесён в `src/data`.
- Имя проекта/репозитория: **`agencyai`** («Бюро» остаётся устным рабочим названием платформы).
- «тиммэлька» из расшифровки = **HTML** (уточнение владельца).
- Прод-вариант: **сборка для демо на GitHub Pages, вся логика и функции — на странице**.

## Что собираем

```
src/web/main.ts      точка входа страницы: реэкспорт модели + монтирование UI
src/web/session.ts   состояние сессии и операторские действия (чистые функции)
src/web/view.ts      рендер состояния в HTML (без DOM-библиотек)
src/web/index.html   каркас страницы (локальные ссылки, viewport, lang="ru")
src/web/style.css    минимальные стили
scripts/build-web.ts Bun.build: src/web/main.ts → demo/app.js (ESM, всё внутри)
                     + копирование index.html и style.css в demo/
```

Итог публикации: `https://baskakovanton.github.io/agencyai/demo/` — страница со списком 30 заявок,
карточкой заявки, кнопками «вперёд/назад/к соседнему узлу», узлами и отчётом. Никаких сетевых
запросов: вся модель в одном `app.js`.

## Требования, которые проверяем тестами

1. Сборка создаёт `demo/app.js`, `demo/index.html`, `demo/style.css`.
2. Бандл **самодостаточен**: нет `http(s)://`, нет внешних импортов/`require`.
3. **Паритет**: при одинаковом seed модель на странице даёт те же заявки и те же переходы,
   что и ядро `src/core` (проверка JSON-равенством).
4. В бандл попала вся модель (30 узлов, названия узлов присутствуют).
5. `index.html`: `lang="ru"`, viewport, только локальные ресурсы (`./app.js`, `./style.css`).

## Порядок

тесты (красные) → реализация → `bun test` (зелёные) → сборка `demo/` → коммит и push → проверка URL.

## Ограничения спеки, которые соблюдаем

- файлы ≤ 200 строк, функциональный стиль без классов;
- `src/core` и `src/data` не знают о среде — их импортирует только точка входа страницы;
- состояние живёт в памяти, на диск пишутся только отчёт и финальное состояние (это и остаётся).
