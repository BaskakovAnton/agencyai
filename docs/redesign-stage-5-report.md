## 2. Доступность

- Axe-core (WCAG 2.1 AA) — 0 нарушений на всех экранах и ширинах.
- Контраст — 0 замечаний: наши AA-варианты поверх палитры кита (вторичный текст, роли на заливке, иконки).
- Кегли — минимум 12 px (в ките встречаются 10–11 px; это наше осознанное отклонение).
- Клавиатура — все основные сценарии: навигация, таблицы, граф, Гант, чат, карточка узла (`Esc`, возврат фокуса), переключатели с `aria-pressed`.
- Декоративные элементы помечены `aria-hidden`; у таблиц `scope="col"` и `caption`; прокручиваемые области — `tabindex="0"` и `role="region"` с подписью.
