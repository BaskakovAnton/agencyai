## 5. Известные ограничения

1. Закрепление заголовков сделано для Ганта; колонки Git-графа внутри SVG закрепить нельзя без пересборки визуализации.
2. Плотность Git-графа — CSS-масштабирование, геометрия SVG не пересчитывается.
3. В реестре и карточке нет колонки «ответственный»: модель не даёт однозначной роли на заявку.
4. История переходов не включает создание заявки (это не `Move`); в Git-графе точка создания отдельная.
5. Остаются подписи 9–10 px (шкала/метки) и часть тач-целей меньше 44 px.
6. Демонстрационные данные: все заявки генерируются моделью, макеты не являются реальными обращениями.
