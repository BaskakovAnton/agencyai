## 2. Сценарий подтверждения (работает по правилам домена)

Панель «Подтверждение завершения»: переключатель «Действовать от имени» (демо-пользователи) и четыре кнопки — «Сообщить о выполнении», «Подтвердить завершение», «Отклонить с причиной», «Переоткрыть». Кнопки активны/заблокированы по правилам модели, а не по желанию интерфейса:

- сдать работу может исполнитель, когда обращение в работе или переоткрыто;
- подтвердить/отклонить — только носитель права `incident.complete` и не тот, кто сдал работу;
- переоткрыть — только носитель права `incident.reopen` для завершённого обращения;
- отказ модели показывается текстом («Отказ модели: нет полномочия …»), состояние не меняется.

Это подтверждено e2e: сдача исполнителем → кнопка подтверждения недоступна → переключение на контролёра → подтверждение → «Завершено» → переоткрытие.

## 5. Известные ограничения

1. **Аутентификации нет**: пользователь для действий выбирается вручную (демонстрация проверки прав); в проде этот выбор даст сессия.
2. **Завершение закрывает все назначения** — карточка честно пишет, что для продолжения нужно новое назначение; автоматический возврат ответственного при переоткрытии не делается (решение за вами).
3. **Действия помечены как демонстрационные**: причины и результаты операций — текстовые заглушки («Сдано исполнителем (демо)»).
4. **История действий** живёт в памяти до перезагрузки: адаптер с сохранением (localStorage или сервер) — следующий шаг.
5. **Распределение по подразделениям в обзоре** считается по активному ответственному; для завершённых обращений подразделение берётся из записи решения (в панели ожидания подтверждения).

## 6. Что предлагается дальше

1. Вернуть ответственное подразделение при переоткрытии (одно правило + тест) — или явно оставить ручное назначение.
2. Адаптер с сохранением состояния (localStorage) и сброс демо-данных.
3. Экран контроля подтверждений: очередь `pending_review` с фильтром «мои как контролёра» (в рамках утверждённого реестра).
4. UX-1 из прошлого исследования: периоды и сравнение с предыдущим, разрезы по категориям — теперь к этому есть доменный фундамент.
