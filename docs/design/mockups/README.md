## Что на макетах

**Вариант A — собственное SVG** (рекомендуемый путь, вариант O3):

1. **Кольцо фаз SLA** на обзоре: 5 в срок / 14 просрочено / 9 без норматива, в центре 28 обращений, рядом текстовая легенда с числами.
2. **Внимание к очереди**: 8 из 28 (29 %), подпись словами — цвет не единственный канал.
3. **Состояния в карточке**: три кольца по фазам SLA (в срок / просрочено / нет норматива) с подписью фазы и норматива.

**Вариант B — библиотека Orbit** (вариант O2): те же три блока на `<o-arc>` и `<o-progress>`, палитра переопределена нашими токенами.

## Типографика

- В HTML — единая шкала: **13 px** вспомогательный текст и легенды, **15 px** заголовки карточек, 18/24 px заголовки разделов.
- В SVG кегль задан в **единицах viewBox**, поэтому кольцо любого размера масштабирует текст пропорционально и он не вылезает за окружность.
- Внутри кольца — только короткое значение (28, 8 из 28, 40 %, 100 %, —); полные подписи и нормативы стоят рядом обычным текстом.
- Было: слово «Просрочено» занимало 107 % ширины кольца (вылет 6 px) и в карточках жили шесть разных кеглей (11/12/12.5/13/15/26). Стало: максимум 46 % ширины и четыре размера (11/13/15/20).

## Замеры (для честного сравнения)

| Показатель | Вариант A | Вариант B |
|---|---|---|
| Зависимости | нет | `@zumer/orbit` (первая рантайм-зависимость) |
| Размер | единицы КБ в нашем бандле | +186 КБ CSS и +31 КБ JS |
| Бюджет demo (лимит 260 КБ) | без изменений | ≈ 425 КБ — лимит придётся поднимать |
| Тёмная и светлая темы | наши токены напрямую | нужен маппинг `--o-*` на наши токены |
| Доступность | подписи и легенды под нашим контролем | нужно добавлять `role`/`aria-*` и клавиатуру |
| Кривая текстовая раскладка, радиальные меню, 3D-слои | нет | есть |

Проверено: макет отрисовывается в chromium, firefox и webkit (5 своих SVG и 7 элементов Orbit, 0 ошибок консоли); на 390 px нет горизонтальной прокрутки, текст не мельче 11 px.
