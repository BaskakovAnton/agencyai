## 2. Наши обязательные исправления (в эталоне их нет)

1. **Контраст AA.** Акцент `#149447` (3.92:1), красный `#e56c7b` (3.11:1), янтарный `#d79b2d` (2.44:1) годятся только как заливки. Для текста — тёмные варианты: `#087638` (5.74:1), `#b3384a`, `#8a5f13`; проверяется аудитом.
2. **Никаких кеглей меньше 12 px** (в эталоне 33 подписи 9–11 px).
3. **Таблицы:** `scope="col"` у всех `th`, `caption` или `aria-label` у таблиц.
4. **Декоративные глифы** — `aria-hidden="true"`.
5. **`:focus-visible`** обязателен для всех интерактивных элементов (в эталоне нет).
6. **Без инлайновых цветов**: только токены; инлайн допускается лишь для геометрии полос графика.
7. **Тёмная тема остаётся** (в эталоне её нет): светлая «forest» — основная, тёмная — по кнопке.

## 3. Что меняем у нас

- `tokens.css` — палитра forest + тёмные текстовые варианты статусов + токены навигации (`--nav-bg`, `--nav-2`, `--nav-text`).
- `shell.css` — тёмный сайдбар с градиентом, топбар 76 px с blur и H1 22 px, нижний блок статуса.
- `nav.ts` / `shell.ts` — подписи групп навигации, бренд-марка зелёная, статус «Демо-данные модели».
- `overview.ts` — новые производные данные: 6 дней-чипов, 6 групп узлов, 6-дневной ряд, матрица SLA по приоритетам × 6 дней с Δ, сводка, шаги процесса.
- `dashboard-html.ts` — композиция как в эталоне: `overview-row` (KPI + полоса дней), `middle-row` (плитки групп + график), `matrix-row` (матрица + сводка), `bottom-row` (процесс + правила).
- `style.css`, `screens.css` — карточки/таблицы/кнопки/чипы в стиле эталона; остальные экраны подхватывают токены и выглядят согласованно.
- `scripts/acceptance-metrics.ts` — приёмка против локально отрендеренного эталона.

## 4. Приёмка

`bun run typecheck`, `bun test`, `bun run e2e`, `bun run build:demo`, `bun run audit` (axe 0, контраст 0, overflow 0), токенный паритет с эталоном ≥ 11/12, скриншоты 5 ширин и сравнение «эталон | реализация».
