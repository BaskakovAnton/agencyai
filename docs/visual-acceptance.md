## 1. Как проверялось

Глазами макеты мне недоступны (модель без image input), поэтому сделаны два независимых объективных инструмента:

1. **Токены и геометрия.** Playwright открывает макет на `:4331` и наш экран на `:4321` и снимает computed-стили: фон и цвет текста, размер шрифта, высота топбара, ширина сайдбара, размер и начертание H1, фон кнопки, радиус, цвет ссылки. Точное совпадение для цветов, допуски для размеров (±1 px шрифт, ±2 px радиус, ±8 px высота, ±10 px ширина). Скрипт `scripts/acceptance-metrics.ts`, данные `docs/screenshots/acceptance/dom-metrics.json`.
2. **Пиксели.** Pillow/NumPy: размеры, средняя абсолютная разница (MAE) по общей области, доля пикселей с отличием > 24, доля акцентного `#2563eb`, пересечение палитр. Скрипт `scripts/visual-acceptance.py`, данные `docs/screenshots/acceptance/metrics.json`, таблица `report.md`.

Макеты — статические страницы с выборочными данными, наш SPA — с 30 реальными заявками модели, поэтому полное попиксельное совпадение недостижимо и не является целью: сверяются токены, композиция и палитра.

## 6. Как включить приём изображений

Сейчас `read_image` отвечает: model deepseek-v4.1-flash does not declare image input. Два способа:

**A. Через интерфейс, без перезапуска.** Settings → Models → провайдер → Customized settings → Model options → строка Input types → отметить Image → сохранить. Запись идёт в `%DSH_HOME%/profiles/<профиль>/cordis.patch.yml` (у нас `C:\Users\Pavel\.dsh\profiles\desktop\cordis.patch.yml`), адаптер перечитывает файл на следующем запросе.

**B. Правкой конфигурации.** В `cordis.patch.yml` у зрячей модели в списке `llm-pi-ai.providers.aitunnel777.models` добавить `input: [text, image]` и переключить `agent-default-model` на неё — в провайдере уже есть `deepseek-v4-flash-vision-exp`:

```yaml
- id: llm-pi-ai
  config:
    providers:
      aitunnel777:
        models:
          - id: deepseek-v4-flash-vision-exp
            input: [text, image]
- id: agent-default-model
  config:
    provider: aitunnel777
    model: deepseek-v4-flash-vision-exp
```

Поле `input` действует только на свою модель; у прямого DeepSeek-адаптера поле называется `inputModalities`, лимиты — `imagePixelBudget` и `imageMaxBytes`. Отмечать Image у текстовой модели бессмысленно: нужна модель, которая действительно принимает изображения.

После включения я смогу открывать макеты и снимки через `read_image` и давать глазное заключение поверх этих цифр.
