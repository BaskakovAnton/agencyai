# Отчёт: этап 3 — карточка обращения

**Статус:** PASS локально, ждёт приёмки · **push не делался**
**Эталон:** `incident-detail.html` из утверждённого каталога.

## 1. Что сделано

Карточка собрана по композиции эталона — пять панелей `ui-panel`:

1. **Шапка заявки** — «Обращение З-015», заголовок, бейдж приоритета, подпись «категория · создано …», четыре факта (`detail-facts`): текущий этап, состояние SLA, ответственная роль, связанная ситуация; описание из ситуации; плашка «только чтение».
2. **История прохождения** — `step-list`: пройденные переходы (`done`), текущий этап (`current`), «Следующий шаг» — варианты модели (на развилке помечено, что веток несколько). Ссылка «Открыть в хронологии».
3. **Контроль SLA** — бейдж фазы, крупное значение («+N ч», «Осталось N ч», «На паузе», «Норматив не задан»), пояснение к состоянию, норматив по приоритету, паузы SLA.
4. **Участники** — роли из модели (инициатор, диспетчер, исполнитель и т.д.) с пояснением роли и инициалами; вымышленных ФИО нет.
5. **Связанные представления** — хронология (Git), Гант, переписка, реестр — все со сохранением id и даты.
