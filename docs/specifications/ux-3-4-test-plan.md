## 1. Принципы

1. **Красный тест сначала:** тест пишется до реализации, падение фиксируется в отчёте пакета.
2. **Уровни:** unit (`bun test`, доменные функции и разметка) и e2e (Playwright, поведение и геометрия).
3. **Геометрия — по замерам DOM**, а не по скриншотам (модель исполнителя не видит изображения).
4. **Регресс обязателен:** существующие `e2e/ux32.spec.ts`, `ux322`, `ux3231`, `ux3233`, `ux324`, `ux4`, `mobile`, `shell` остаются зелёными.
5. **Никаких ослаблений:** существующие проверки не удаляются и не смягчаются; тест можно только уточнить вместе с требованием.

## 6. Гейты приёмки

Пакет считается сданным, если:

1. Красный тест зафиксирован, затем зелёный.
2. `typecheck` чисто, `bun test` 0 падений, `bun run e2e` 0 падений.
3. `build:demo` детерминирован (тот же SHA-256 при повторной сборке).
4. Файлы ≤ 200 строк; `git diff --check` чисто.
5. CI success, Pages на коммите пакета, живая проверка без ошибок консоли.
