## 1. Где сейчас тонко (FACT)

| Факт | Последствие |
|---|---|
| e2e идёт **только в chromium** | поведение в Safari/Firefox (особенно `details`, `sticky`, `has()`, `checkVisibility`) не проверено |
| `verify-live` существует как скрипт, но **не в CI** | публикация проверяется вручную, регресс на живом сайте заметит только владелец |
| Близко к лимиту 200 строк: `components.css` 196, `timeline-html.ts` 195, `style.css` 195, `audit-ui.ts` 192, `overview.ts` 191 | следующая правка упрётся в лимит и потребует срочного сплита |
| Реестр умеет только экран: **нет выгрузки** данных за срез/период | приёмной нужен CSV/JSON для отчётности |
| Печать покрывает **только карточку** | список реестра и отчёт за период печатаются как экран |
| Продуктовый слой — discovery, реализации нет (OD-6=B) | данные живут в памяти, перезагрузка теряет состояние |
| 15 документов discovery/review локальны по правилу OD-1=B | правило записано, но файлы могут «потеряться» вне Git |
| Бюджета размера бандла нет | рост 161 КБ никем не ограничен |

4. Коммит, push, CI и Pages успешны; для публикационных пакетов — живая проверка.
5. Отчёт или строка в журнале с числами и ссылкой на коммит.
