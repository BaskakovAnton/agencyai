## 1. Что даёт пилот

Оператор выполняет действия по обращению (сдвиг этапа, назначение подразделения, подтверждение завершения), изменения переживают перезагрузку страницы, а снимок можно выгрузить и загрузить обратно файлом. Серверной части и персональных данных нет: всё живёт в браузере.

## 2. Предусловие: модель изменений

Сейчас демо только для чтения (карточка сообщает «сведения доступны только для просмотра»). Пилот невозможен, пока не появится явный набор действий оператора:

| ID | Действие | Доменная операция |
|---|---|---|
| M1 | Сдвинуть обращение на следующий узел | `moveForward` / `moveToNode` |
| M2 | Назначить подразделение | `assignDepartment` |
| M3 | Подтвердить завершение | `approveCompletion` / `submitExecution` |

Права ролей уже реализованы в `src/core/org`; интерфейс лишь вызывает операции и показывает результат.

## 3. Хранение

| ID | Требование |
|---|---|
| R-S1 | IndexedDB, база `deputat360`, версия 1, хранилище `workspace` |
| R-S2 | Сохраняется весь `OrgWorkspace` плюс список обращений и версия схемы |
