### BLOCKER

**B1. Каталог `docs/reports/` игнорируется Git — отчёты не попадут в коммит.**

- **ID:** B1 · **Уровень:** BLOCKER (процедурный, не функциональный).
- **Файл и место:** `.gitignore`, строка 22 — правило `reports/`; затрагивает `docs/reports/`.
- **Шаги воспроизведения:**
  1. `git check-ignore -v docs/reports/ux-3-kpi-periods.md` → ответ `.gitignore:22:reports/`;
  2. `git ls-files docs/reports` → пусто;
  3. `git log --oneline -- docs/reports` → коммитов нет;
  4. `git status --ignored --short docs/reports` → `!! docs/reports/`.
- **Фактическое поведение:** все четыре отчёта существуют только в рабочем дереве; `git status` их не показывает, `git add -A` не добавит.

- **Уточнение к выводу UX-3.1:** проблема №4 из задания проверялась по **рабочему** дереву (файл найден) — в **отслеживаемом** дереве отчёта действительно нет, то есть замечание владельца было верным.
- **Минимальное решение (одно из):** заменить `reports/` на `/reports/` (тогда якорь действует только в корне) **или** добавить после строки 22 исключение `!docs/reports/` и `!docs/reports/**`; разовая альтернатива — `git add -f docs/reports` перед коммитом. ## 15. Ограничения

1. «Текущая дата модели» — последний день среза, а не системная дата.
2. Все события одного дня имеют одинаковый timestamp (12:00 UTC): порядок определяется порядком записи.
3. Обращения без записей lifecycle завершёнными не считаются — осознанное ограничение.
4. Рейтинг подразделений по SLA не строится (атрибуция просрочки недостоверна).
5. Боевая версия на GitHub Pages не проверялась: публикация запрещена условием задания.
