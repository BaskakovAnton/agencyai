## 10. Почему понадобился второй коммит

Штатная сборка обновляет не только app.js: блок F этапа UX-3.2.4 добавил в src/web/components.css стили панели чипов (.incident-chips/.incident-chip), поэтому build:demo изменил и demo/components.css. В первый релизный коммит он не попал (в индексе были только app.js и отчёт), из-за чего опубликованные чипы остались бы без стилей. Причина установлена сравнением исходного и собранного CSS (хеши совпадают), файл добавлен вторым коммитом; публикация проверена повторно.
