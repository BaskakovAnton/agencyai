# UX-3.3 - отчёт о дизайне (Этап 3)

## 1. Итоговый статус

DESIGN ACCEPTED (итоговый аудит редакции 1E). Дизайн-спецификация подготовлена для шести блоков UX-3.3 на основании утверждённых SPEC и DISC; замечания Stage 3B устранены в редакции 3C, решение владельца DEC-UX33-05 внесено в редакции 3D: открытый вопрос по нескольким передачам внутри дня закрыт. Окончательная приёмка остаётся за владельцем продукта. Приложение, тесты, CSS, конфигурация и demo не изменялись; коммитов и push нет.

## 4. Список ключевых дизайн-решений

1. Мобильный реестр: карточка строки с шестью обязательными полями, зоны касания 44 px, без таблицы ниже 768 px (SPEC 5, DEC-33-02).
2. Планшет: таблица с сохранением четырёх обязательных колонок и скрытием только Изменено и Карточка.
3. Хронология: зоны касания 44 px без изменения отрисовки; вертикальный граф ниже 768 px; передача подразделения оформляется тем же компонентом, что в карточке.
4. Карточка: семь блоков в фиксированном порядке; блок Передачи из назначений; блок Что дальше с шестью честными состояниями.
5. Dashboard: четыре периода, подпись базы сравнения, отсутствие процентов при нулевой базе, переходы только из моментных показателей.
6. Design System: палитра токенизируется без новых цветов, реестр из 12 компонентов, высоты контролов 36 и 44 px.
7. Историческая атрибуция: единый departmentOn с правилом конца дня, семь различимых визуальных состояний, отсутствие данных не подменяется значением Без подразделения.
8. Доступность: фокус 2 px, aria-live счётчика, статусы текстом и цветом, разделение автоматических и ручных проверок.

## 7. Риски и ограничения

1. Блок F меняет состав реестра на исторических датах: требуется регрессия на 25 днях и на текущем дне до снятия пояснения F5.
2. Целевые зоны касания 44 px на хронологии затрагивают плотную отрисовку: риск визуального смещения, проверяется на 390 px.
3. Токенизация CSS может дать визуальную регрессию: блок E выполняется последним, с проверкой на восьми ширинах.
4. UNKNOWN: физические мобильные устройства недоступны, проверка выполняется эмуляцией viewport.
5. Ограничение: HTML-эталоны не созданы, макеты описаны схемами и таблицами.
