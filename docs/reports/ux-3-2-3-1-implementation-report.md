- Счётчик: `overview.org.waitingForReview` ← `orgFactsFor` ← `waitingForReview` (`org-integration.ts:85`) — **текущий** статус.

## 12. Ограничения

1. **INFERENCE:** ссылки на `view`/`department` видны в адресе, но UI-контролов для этих фильтров пока нет — они относятся к UX-3.2.4; после перехода пользователь понимает контекст по адресу и составу списка.
2. **FACT:** атрибуция подразделения в модели дана на текущий момент (`accountableOf`), поэтому ссылка `department=<id>` показывает текущее распределение по подразделению, а не «кто отвечал в тот день» (ограничение F5 аудита UX-3.2.1, не входит в scope).
3. **FACT:** обращения без записей жизненного цикла в очередь не попадают (осознанное ограничение UX-3.1) — инвариант счётчик = список сохраняется, так как оба используют один Snapshot.
4. **UNKNOWN:** нужен ли отдельный показатель «обращения без ответственного» на обзор — вне scope (вопрос из discovery).
