## 13. Открытые замечания

1. **Генерируемые артефакты.** Для e2e выполнялась `bun run build:demo` (webServer отдаёт `demo/`), для аудита — `bun run audit` (обновляет `docs/screenshots/audit/**`). После проверок оба артефакта **восстановлены до состояния HEAD**, поэтому в дереве нет изменений сборки и снимков; пересборка произойдёт при подготовке релиза UX-3.2.
2. **`incident-actor.ts` — только задел.** Модуль содержит перенесённый `linksBlock` (13 строк); блок «Действует сейчас» и длительности добавляются в UX-3.2.5, сейчас их нет.
3. **M3 частично закрыт:** `src/web/timeline-view.ts` больше не нарушает лимит (203 → 107). Пре-существующее нарушение `tests/web.test.ts` (213 строк) остаётся и в объём UX-3.2.0 не входит.
4. **Поведение вне браузера.** Идентичность обработчиков подтверждена DOM-сравнением и e2e; отдельного unit-теста на DOM-обработчики нет (Bun-тесты проекта работают без DOM) — это осознанное ограничение, а не пропуск.
